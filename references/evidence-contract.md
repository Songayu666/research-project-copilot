# 科研证据等级

所有会影响研究结论的陈述、数值和图表都应记录来源。使用以下五级标签：

| 标签 | 定义 | 允许的表达 |
| --- | --- | --- |
| 已验证 | 已从原始数据重新计算、运行代码或交叉核对 | “结果显示……”并说明验证方法 |
| 代码声明 | 来自代码、配置或注释，但未重新运行 | “代码设置为……” |
| 合理推断 | 根据文件结构、公式或上下文推断 | “根据现有代码推断……” |
| 待核实 | 单位、缩放、参数来源或结果版本不明确 | 只描述观察，不作确定性物理解读 |
| 研究计划 | 尚未实现或没有结果 | 使用“拟开展”“计划验证” |

## 规则

- 不把“代码可运行”等同于“科学结论成立”。
- 不把绘图显示缩放后的数值直接解释为真实物理量。
- 不把独立示例代码描述为已经接入主模型。
- PPT正文保持自然，不必给每句话加标签；在备注、方法页、结果说明或交付报告中体现证据等级。
- 每个关键数值至少记录：变量名、来源文件或数据集、计算方法、单位和验证状态。
- 无法确认时降级为“待核实”，不要补全或猜测。
