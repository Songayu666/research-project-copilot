# 图片型科研答辩 PPT 规范

## 先选择汇报类型

- 组会进展：研究对象 → 已完成工作 → 当前结果 → 问题 → 下一步。
- 开题答辩：背景 → 科学问题 → 技术路线 → 创新点 → 可行性 → 计划。
- 中期答辩：目标 → 已完成进度 → 阶段结果 → 偏差与调整 → 后续安排。
- 毕业答辩：问题 → 方法 → 实验 → 结果 → 创新 → 结论。
- 论文汇报：论文问题 → 方法 → 证据链 → 局限 → 批判性评价。

页数由内容和汇报时长决定。以下约10页结构只作为缺少其他信息时的起点。

## 通用叙事（约 10 页）

1. 封面：题目、副标题、汇报信息。
2. 背景与痛点：现实问题、研究空白、核心矛盾。
3. 研究问题与目标：问题树或目标分解。
4. 总体技术路线：从数据到结论的完整研究框图。
5. 数据与预处理：来源、输入、质量控制、划分。
6. 核心方法/模型：模块关系和信息流。
7. 实现过程：程序栈、训练/推理流程、关键接口。
8. 基线与创新点：原始方法和拟改进方法的公平对比。
9. 实验与评价：指标、对照、消融、预期证据；无真实结果时明确写“实验设计”，不伪造结果。
10. 结论、风险与下一步。

神经网络项目可增加一页“逐层结构”：用表格或展开式网络图列出层/模块、输入尺寸、输出尺寸、参数或操作、作用；复杂模型按 stage/block 展示，不强行把每个重复层塞入一页。

## 从用户参考图制定视觉系统

1. 优先使用用户本次提供的 PPT 参考图；一张即可。先实际查看图片，再制定色板，不凭文件名猜测。
2. 若未提供新图，自动使用用户最初提供的 `assets/palette-reference.png`：主色 `#8C2C38`、辅色 `#A84F5A`、柔粉 `#C47982`、浅粉灰 `#F1E7E7`（浅色为近似值）。不为缺少新图而暂停或要求重复上传。用户明确指定的配色优先于参考图及默认色板。
3. 页面底色始终为白色 `#FFFFFF`，即使参考图是深色背景也保持白底。从参考图的图形、标题、色块等提取适合白底的主色、辅色、强调色、正文色和线条色，忽略照片的偶然颜色、浏览器边框及水印。
4. 在输出目录保存 `visual-style.md`，写明参考图路径、各颜色的 HEX 和用途，以及字体气质、标题层级、线宽、圆角、留白与信息密度。视觉估计的 HEX 应注明“近似提取”，不要声称是精确取样。
5. 对比不足的颜色用于浅底色块或装饰；文字采用该色系的深色变体或近黑中性色。必要的浅色填充可由提取色与白色混合得到，记录调整理由。
6. 将同一视觉系统写入每页出图提示词。内容决定版式：过程用流程图，对照用并列布局，模型用层级结构；不强制每页使用同一模板或固定模块数量。

用户明确指定的配色与清晰度要求优先于下游生成技能的默认风格、高密度要求和颜色偏好。配色优先级为：用户明确指定 > 本次上传参考图 > 内置的原始酒红参考图。白底要求始终保留。

## 视觉约束

- 每次生成一张完整页面，画布 16:9；各页独立出图，最终共约 10 张。
- 白底 `#FFFFFF`，其余配色遵循本次 `visual-style.md`，不固定酒红、蓝色或其他主题色。
- 以图形、结构、色块为主，文字为辅；留白充足，箭头方向一致，标题层级稳定。
- 全套统一字体气质、线宽、圆角、阴影和图标风格；每页结构可变化，但视觉系统不变。
- 参考图只用于布局骨架，不复制其品牌、文字、数据或水印。
- 页面文字使用用户语言，专有名词可保留英文；避免生成不存在的数据和结论。

## 数据精确模式

出现坐标轴、统计值、误差线、热图、混淆矩阵、实验曲线或科学图像时默认启用：

1. 用用户指定的 Python/R 后端从真实数据生成图表，保留代码与矢量或高分辨率输出。
2. 图表中的数据点、坐标、图例、单位和统计标注不得交给图像模型重绘。
3. PPT可以使用原始图表文件直接排版；图像模型只生成背景、装饰或不承载数据的示意图。
4. 若必须交付“每页一张图”的图片型PPT，先用可编辑PPT或排版工具将原始图表放入页面，再整体导出页面图；在交付说明中记录该页采用混合合成。
5. 纯概念框图、封面和无精确数据的示意页可以继续使用整页图像生成。

数据精确性优先于整页生成方式。不得为了视觉统一而改变真实曲线或数值。

## 逐页验收

确认页面不是拼贴长图；底色为白色；颜色能追溯到用户指定、新参考图或内置原始色板；标题与正文可读；内容无截断；核心结论 3 秒内可定位；精确图表与源数据一致；图例、单位、输入输出和箭头语义一致；图片之间风格统一。失败页单独重做，不降低整套标准。
