# 科研图与PPT版式模式

按内容关系选择结构，不固定模板：

| 内容 | 推荐结构 |
| --- | --- |
| 数据 → 方法 → 结果 | 左到右多阶段流程，阶段间单向箭头 |
| 多源数据汇聚 | 左侧输入簇 → 中央处理管线 → 右侧输出 |
| 分层模型或神经网络 | 自下而上层级图，标出每层输入输出 |
| 原始方法与改进方法 | 左右对照，中间突出改动与公平比较条件 |
| 多模块耦合 | 中心系统 + 周边模块，反馈回路使用不同线型 |
| 多组实验结果 | 主图 + 指标卡 + 误差/局部放大区 |
| 风险与下一步 | 已完成 / 待核实 / 下一步三列路线图 |

白底页面使用克制的色块、统一线宽、短箭头和清晰标题层级。流程主路径从左到右或从上到下；模块名用名词，箭头标签用动词。不要复制外部参考图的文字、数据、品牌或水印。
